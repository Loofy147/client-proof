# Engineering Services

Practical implementation for integrations, automation, and reliability problems.

## 1. API Integration Fix

**Indicative starting scope:** $250–$500

Connect an existing API or webhook flow, validate inputs, handle authentication and errors, add deterministic tests, and provide a handoff note.

Best fit:
- REST API integrations
- webhook ingestion
- third-party service connections
- broken API flows

## 2. Workflow Repair & Stabilization

**Indicative starting scope:** $350–$750

Diagnose a failing or unreliable workflow, repair the execution path, add idempotency/error handling where needed, and verify the resulting behavior.

Best fit:
- duplicate actions after retries
- broken automations
- API failure handling
- workflow state/verification problems

## 3. MCP / AI Integration

**Indicative starting scope:** $500–$1,500

Integrate an MCP server/client with existing APIs or business systems, with typed tool inputs, authentication, structured results, error handling, tests, and clear handoff documentation.

Best fit:
- MCP → REST integrations
- AI tool execution
- Claude/OpenAI/other model integrations
- bounded agent workflows

## Delivery contract

Every engagement is scoped around an observable outcome:

**problem → implementation → test → verification → evidence → handoff**

I do not claim customer-production history for portfolio work. Public proofs are labeled according to their evidence status.
